METHODOLOGY

How AquaPredict works

  1. Load the rainfall and flood datasets.
  2. Clean missing values, dates, state names and invalid rainfall values.
  3. Create cyclical calendar features and normal rainfall features.
  4. Compare Extra Trees and Random Forest regression.
  5. Evaluate using MAE, RMSE and R² on a later date period.
  6. Use the selected model to generate rainfall estimates.
  7. Summarise historical flood events by state and month.
Limitations

The model does not use live weather feeds, satellite imagery, radar observations or real-time river levels. Its seven-day output is a model-based estimate from historical features. The flood dataset does not provide verified non-flood examples, so it cannot train a reliable future flood/no-flood classifier.
